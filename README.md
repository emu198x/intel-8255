# intel-8255

The Intel 8255 programmable peripheral interface.

| Crate | Registry |
|---|---|
| [`emu198x-intel-8255`](crates/emu198x-intel-8255) | [crates.io](https://crates.io/crates/emu198x-intel-8255) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Acorn Atom, Amstrad CPC, MSX and Spectravideo.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
